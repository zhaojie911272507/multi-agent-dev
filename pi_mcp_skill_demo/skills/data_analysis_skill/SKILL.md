# 数据汇总与数字报告技能

本技能指导智能体完成「数字 → 计算 → 报告」的完整流程，
需要配合 MCP 计算工具（`mcp__math__*`）一起使用。

## 使用步骤

1. **提取数字**：从用户消息中提取出需要分析的数值列表，标注含义
   （如销售额、用户数、温度等）。

2. **调用计算工具**：使用 MCP 计算工具完成汇总，必须调用真实工具，
   禁止心算或估算：
   - `mcp__math__add` 计算总和
   - `mcp__math__subtract` 计算差值
   - `mcp__math__multiply` 计算乘积（如平均值的分子）
   - `mcp__math__divide` 计算商（如平均值）

3. **关键指标**（根据需求计算，至少包含总和与平均值）：
   - 总和 = add 逐个累加
   - 平均值 = divide(总和, 数量)

4. **输出报告**：按以下模板输出：

   ```
   ## 数据分析报告
   - 数据点：...
   - 总和：...
   - 平均值：...
   - 分析结论：...
   ```

5. **注意事项**：
   - 所有数值都必须来自工具返回结果，工具返回前不得在报告中填写数字
   - 若计算中间结果异常（如除 0 报错），如实说明错误原因
